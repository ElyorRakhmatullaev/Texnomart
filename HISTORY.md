## 2026-06-12 — Texnomart Promo: sidebar active-state on internal routes + flush-left filter dropdowns
Two UX fixes. **Sidebar active state on detail/internal pages**: the shared `AppShell` computed `isActive` as an exact `location.pathname === item.href`, so navigating to a child route (`/short-calendar/:id`, `/approvals/:id`, `/promo-types/:ruleId`) dropped the parent nav item's highlight. Added an `isNavItemActive(pathname, href)` helper (exact match OR child path via `pathname.startsWith(href + "/")`, with the root `/` kept exact-only) and used it for `SidebarMenuButton.isActive` — the parent item now stays highlighted on its internal pages. General improvement, so Dashboard's detail routes benefit too; verified `build:dashboard` + `build:promo` pass and that exactly one item is active across `/short-calendar/:id`, `/approvals/:id`, `/audit`. **Flush-left filter dropdowns**: the full calendar already passed `bg-transparent px-0` to the shared `FilterBar` (no gray box, dropdowns flush-left with the title/grid); applied the same to the short-calendar, approvals, and notifications FilterBars, and dropped the gray box on the S8 audit-log filters — so every Promo screen's dropdowns now sit on the same left line as the page title and table (the reports pickers already aligned). Dashboard's FilterBars keep the default gray box (Promo-only change). Verified in-browser at 1440px: short-calendar/audit dropdowns align flush-left with the H1 + table, and the «Краткий промо-календарь»/«Согласование»/«Аудит-лог» items stay active on their internal pages.
