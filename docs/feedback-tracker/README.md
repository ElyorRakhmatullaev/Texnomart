## Перегенерация

```bash
node docs/feedback-tracker/build-tracker.js        # пишет .xlsx на Desktop (пути захардкожены под эту машину)
powershell -File docs/feedback-tracker/format-tracker.ps1   # перенос текста, закреп шапки, цвет групп колонок
```

- `build-tracker.js` берёт SheetJS из workspace (`createRequire` от `Promo/package.json`) — нужен установленный `pnpm install`.
- Датасет строк (дословные тексты комментариев + статусы дизайн-прототипа) захардкожен внутри `build-tracker.js` — при новых раундах фидбэка добавлять строки туда и перегенерировать.
- `format-tracker.ps1` — UTF-8 **с BOM** (обязательно для PS 5.1 с кириллицей).

Источники дословных текстов: 8 `.docx` + трекер `.xlsx` в `Desktop\Texnomart` + PDF «7-й части» (передан в чат 22.07.2026; комментарии клиента в нём — блоки «Ответ от Texnomart»). Внутренний gap-анализ по трекеру: `docs/promo_feedback_tracker.md`.
