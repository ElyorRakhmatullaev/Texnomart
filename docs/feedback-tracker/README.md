## Перегенерация

```bash
node docs/feedback-tracker/build-tracker.cjs       # пишет .xlsx на Desktop (пути захардкожены под эту машину)
powershell -File docs/feedback-tracker/format-tracker.ps1   # перенос текста, закреп шапки, цвет групп колонок
```

- Расширение **`.cjs` обязательно**: в корневом `package.json` стоит `"type": "module"`, и как `.js` этот CommonJS-скрипт больше не запускается (переименован 05.08.2026).
- `build-tracker.cjs` берёт SheetJS из workspace (`createRequire` от `Promo/package.json`) — нужен установленный `pnpm install`.
- Датасет строк (дословные тексты комментариев + статусы дизайн-прототипа) захардкожен внутри `build-tracker.cjs` — при новых раундах фидбэка добавлять строки туда и перегенерировать.
- `format-tracker.ps1` — UTF-8 **с BOM** (обязательно для PS 5.1 с кириллицей).
