# /commit

Group uncommitted changes by topic and create separate commits for each group, then push.

### Step 1: Analyze Changes
Run `git status` and `git diff` (staged + unstaged) to see all modified / untracked files.

### Step 2: Group by Topic
Classify each changed file into a topic group:

**Grouping rules (in priority / dependency order):**
1. **Shared UI** — `packages/ui/src/*` (shadcn components, utils)
2. **Root Config** — `package.json`, `pnpm-workspace.yaml`, `.gitignore`, `CLAUDE.md`, `styles-config.md`
3. **Rules & Commands** — `.claude/rules/*`, `.claude/commands/*`
4. **Dashboard: Styles & Tokens** — `Dashboard/src/styles/*`
5. **Dashboard: Mock Data** — `Dashboard/src/lib/*`
6. **Dashboard: Auth** — `Dashboard/src/app/components/auth/*`
7. **Dashboard: Layout & Shell** — `Dashboard/src/app/components/AppShell.tsx`, `Dashboard/src/app/routes.tsx`
8. **Dashboard: Pages** — `Dashboard/src/app/components/<module>/*`
9. **Dashboard: Config** — `Dashboard/package.json`, `Dashboard/vite.config.ts`, `Dashboard/CLAUDE.md`
10. **Promo: Styles** — `Promo/src/styles/*`
11. **Promo: App Shell** — `Promo/src/App.tsx`
12. **Promo: Pages** — `Promo/src/pages/*`
13. **Promo: Config** — `Promo/package.json`, `Promo/vite.config.ts`, `Promo/CLAUDE.md`
14. **Docs** — `*/docs/*`, `*/HISTORY.md`, `*/tasks/*`

If files are tightly coupled for one logical change, group them together.

### Step 3: Present Plan
Show the proposed commit groups:

```
Group 1: [topic] — N files
  - file1.ts
  - file2.tsx
  Commit message: "type(scope): description"
```

Wait for user approval before proceeding.

### Step 4: Commit Each Group
For each approved group, in dependency order (shared first → styles → components → config last):
1. `git add <specific files>`
2. `git commit -m "<message>"`

**Commit message format:**
- Prefix: `feat:`, `fix:`, `refactor:`, `docs:`, `chore:`, `style:`, `test:`
- Include scope: `feat(dashboard): add partner distribution donut chart`
- First line under 72 chars
- NEVER include "Co-Authored-By", "Generated by", or any AI / Claude signature

### Step 5: Push
```bash
git push
```

### Rules
- NEVER use `git add -A` or `git add .` — always add specific files
- NEVER commit `.env`, `node_modules/`, `logs/`, or binaries > 5MB
- Never include AI attribution lines in commit messages
- If unsure about grouping, ask the user
